# Investigation Findings

## Finding 1: Header Anomaly (X-Mailer)

- **Observation:** The `X-Mailer` header revealed the email was sent using `PHP/8.1.2`.
- **Risk Level:** High.
- **Analysis:** The organization's legitimate emails are routed through Microsoft 365. An email claiming to be from the CEO sent via a PHP script indicates the email was generated by a malicious script hosted on a web server, not the CEO's Outlook client.

## Finding 2: Infrastructure Spoofing

- **Observation:** The sending IP (`185.199.108.153`) resolves to a cloud hosting provider, not the corporate email gateway.
- **Risk Level:** High.
- **Analysis:** The attacker set up a fake mail server on a cheap VPS to spoof the CEO's address, exploiting a DMARC policy of `p=NONE` (which only monitors, but does not reject, failing emails).

## Finding 3: Social Engineering (Gift Card Scam)

- **Observation:** The email requested the purchase of gift cards while claiming to be in "back-to-back meetings."
- **Risk Level:** Critical.
- **Analysis:** This is a classic pretext to prevent the victim from calling the CEO to verify the request.
