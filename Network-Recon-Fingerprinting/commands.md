# Command Reference & Analysis: Network Reconnaissance

This document outlines the exact commands used to perform the network sweep, scan the target, and capture the resulting traffic.

## Phase 1: Target Discovery & Baseline

_Establishing connectivity and identifying the target's IP address._

| Command             | Purpose                                                                                   |
| :------------------ | :---------------------------------------------------------------------------------------- |
| `ip a`              | Run on the **target VM** to identify its IP address on the local network.                 |
| `ping -c 4 <VM_IP>` | Run on the **attacker laptop** to verify ICMP connectivity to the target before scanning. |

## Phase 2: Deep Service Fingerprinting (Attacker)

_Using Nmap to discover open ports, running services, and the operating system._

| Command                        | Purpose                                                                                                                                                                    |
| :----------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sudo nmap -sS -sV -O <VM_IP>` | The primary scan. `-sS` performs a stealth SYN scan, `-sV` probes open ports to determine service/version info, and `-O` attempts to identify the target operating system. |

## Phase 3: Service Banner Grabbing (Attacker)

_Forcing a full TCP connection to extract the raw service banner._

| Command                      | Purpose                                                                                                                                                                  |
| :--------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nmap -sT -sV -p 22 <VM_IP>` | Uses a TCP Connect scan (`-sT`) specifically on port 22. Unlike the stealth scan, this completes the 3-way handshake, forcing the SSH server to send its version banner. |

## Phase 4: Traffic Capture (Defender)

_Capturing the scan from the network perspective to understand how it looks to a defender._

| Command / Action                           | Purpose                                                                                                           |
| :----------------------------------------- | :---------------------------------------------------------------------------------------------------------------- |
| Wireshark capture on active interface      | Started before running Nmap to record the raw packets.                                                            |
| `tcp.flags.syn == 1 && tcp.flags.ack == 0` | **Wireshark Filter:** Isolates the initial SYN packets generated by the scan, proving the reconnaissance attempt. |
| `tcp.port == 22`                           | **Wireshark Filter:** Isolates the SSH traffic to find the `[PSH, ACK]` packet containing the service banner.     |
| Right-click -> **Follow > TCP Stream**     | Reconstructs the conversation to read the plaintext `SSH-2.0-OpenSSH...` banner.                                  |
